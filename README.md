# Meepcoin
Meepcoin. Privacy Coin, but meepy. Browser minable.

## Try the demo

Download the Windows installer or portable app from [Releases](https://github.com/jjtseng-jjtseng/Meepcoin/releases).

1. Install the app, or run the portable EXE.
2. Open MeepCoin Local Lab
3. Open through app or through browser. 
4. Click Start mining.


## Features

- Real MeepHash hashing.
- Live hashrate, block count, and demo MEEP balance.
- Solo mining or private mining rooms.
- Multiple devices can compete in the same room.
- Start and stop mining from the dashboard.
- NOTE: technically, your hashrate could be faster but that would require reserving ram (which would fire a bunch of virus warnings)

Also, if your thing keeps finding MEEP, its becuase the difficulty is too low. Final product will have adaptive difficulty, the more people are mining, the harder it is to actually find the block.

## Current status
