# Readiness after the bounded deployment rehearsal

The deployed desktop invitation rehearsal is complete for its recorded finite
scope. It stopped and expired; it is not a continuously operating public network.
The next six product areas are distinct from that completed deployment checklist.

| Area | Current evidence | Still required |
|---|---|---|

Real offline native tests and a visible Chromium browser payment passed. | Complete Windows/macOS native distributions and installers; native filesystem and update protections on those systems; standalone website signing if that is the intended product. |
| Participant journey | Native browser-mined rewards and transfers were verified in the prior deployment. The new wallet UI supplies the public address and handles a real transfer and exact recipient credit. | One complete fresh-release participant rehearsal using the installed wallet on each advertised platform, its actual invitation and the live mining endpoint. Persistent participant wallets belong on participant devices. |
